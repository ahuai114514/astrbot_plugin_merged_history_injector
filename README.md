# astrbot_plugin_merged_history_injector

该项目由 Codex 编写。

这是一个 AstrBot 插件，用来把用户“引用的一段 QQ 合并转发聊天记录”展开后，按 AstrBot 的 `contexts` 历史格式写入当前会话的持久化历史。

## 作用

插件仅在同时满足下面条件时接管消息：

- 用户引用了一条已有消息
- 被引用消息本身包含 QQ 合并转发
- 当前消息内容严格为 `@bot 导入聊天记录`（允许空白差异）

普通引用、`@bot` 后提出其他问题、未引用消息时发送导入指令，都不会触发历史导入。

命中后，插件会：

1. 展开被引用的合并转发记录
2. 转成 `[{role, content:[{type:"text", text:"..."}]}]` 结构
3. 写入当前会话的持久化历史
4. 返回一条导入成功提示，不继续触发本次聊天

## 注入策略

- 默认把转发记录映射成多条 `user` 历史消息
- 每条消息会保留发送者昵称前缀，例如 `[张三] 你好`
- 如无法抓取转发正文，会回退成一条摘要文本历史

这个插件只负责“导入并记住历史”，不负责总结、分析或改写聊天记录任务。
同一段导入内容会做一次基础去重，避免在完全相同的导入块已存在时反复追加。

## 文件说明

- `main.py`：插件入口与 hook 编排
- `forward_resolver.py`：引用消息、合并转发、payload 抓取与文本回退
- `history_builder.py`：把转发内容映射成 AstrBot `contexts` 格式
- `_conf_schema.json`：插件配置
- `metadata.yaml`：插件元数据
- `requirements.txt`：依赖声明
- `LICENSE`：MIT 协议

## 配置项

- `enabled`：插件总开关
- `debug_logging`：是否打印调试日志
- `processing_message`：导入成功后发送的短提示，留空则不发送
- `max_depth`：嵌套展开深度限制
- `max_nodes`：最多解析节点数
- `max_chars`：回退文本或单条拼接时的最大字符数
- `header_text`：导入历史前附加的一条文本头，留空则不加

## 说明

该插件会把整理后的记录追加到当前会话的持久化历史中，因此后续几轮对话在同一会话下也能继续看到这段内容。当前这一条“引用并导入”的消息本身不会继续触发 LLM 回复。
